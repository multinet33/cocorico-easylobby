# Cocorico EasyLobby

**Tu vas fragguer dans Call of ? Coco va te faciliter la vie.** 🐓
*Gonna frag in Call of Duty? Coco makes your life easier.* — [English below](#english)

Appli Windows pour jouer à Call of Duty sur des serveurs proches de chez toi : Geofence (filtre des
datacenters hors de ta zone), VPN de lobby intégré, escouade entre amis (la CocoSquad), Coco HUD, analyse de tes parties.
Interface en français ou en anglais.

## Télécharger

👉 **[Dernière version : CocoricoGeofence.exe](https://github.com/multinet33/cocorico-easylobby/releases/latest)**

## Installer

1. Télécharge `CocoricoGeofence.exe` (rien d'autre à installer).
2. Clic droit → **Exécuter en tant qu'administrateur** (le filtre passe par le pare-feu Windows).
3. Windows peut afficher « Windows a protégé votre ordinateur » : l'appli n'est pas signée.
   Clique sur **Informations complémentaires** → **Exécuter quand même**.
4. Lance l'appli **avant** Call of Duty.

**Mises à jour** : à partir de la 2.1, l'appli te propose toute seule les nouvelles versions au démarrage (nouveautés
affichées, installation jeu fermé) ; à partir de la 2.1.3, elle est imposée au 3e lancement sans l'installer. Depuis une version plus ancienne : quitte l'appli, remplace le `.exe`, relance-le.
Tes réglages, ton historique et tes trophées sont gardés.

## Activation

L'appli fonctionne **7 jours en essai**. Pour continuer, envoie à l'auteur ta **clé machine** (Guide → 🔑 Activation,
format `CCEL-XXXX-XXXX-XXXX-XXXX`) : il te renvoie un **code d'activation** qui ne marche que sur ton PC.
Sans code, rien n'est effacé : historique, réglages et trophées reviennent dès l'activation.

## Ce qu'il y a dedans

- 🎯 **Smart Geofence** : zone par ping, carte des pings, Smart Expand si la recherche traîne
- 🧠 **Lobby Intelligence & Insights** : meilleur créneau, meilleure région, ping limite, pour toi
- 👥 **CocoSquad** : Squad Sync, Squad Lead (mode Groupe), Squad Recap, trophées
- 🔒 **VPN Lobby** intégré (seul le matchmaking passe par le VPN)
- 🖥️ **Coco HUD** par-dessus le jeu, statut Discord, lecture de l'écran de fin
- 🔔 **Coco Alerts** sur ton téléphone, 🧪 **Coco Lab**, **Magic NAT** (expérimental)

Le détail de chaque version est dans les [notes de version](https://github.com/multinet33/cocorico-easylobby/releases).

## Vie privée

L'appli envoie des statistiques d'usage **anonymes** à l'auteur, chiffrées pour lui seul : version, fonctions utilisées,
pays et région de l'IP publique, santé de l'appli, résumé de tes parties, type de connexion… Jamais de pseudo, d'adresse
IP, de ville, de zone, de clé machine ni de code d'escouade. Le détail exact est visible dans le Guide, et l'envoi se
désactive d'un clic.
